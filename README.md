# Yapay Zekânın İçi

Bir dil modelinin nasıl çalıştığını, nasıl eğitildiğini, nasıl "düşündüğünü", araçları nasıl kullandığını, efor ayarının neyi değiştirdiğini ve Fable ile Sonnet arasındaki farkı sade bir Türkçeyle, oynanabilir animasyonlarla anlatan tek sayfalık site.

Açmak için `index.html` dosyasını tarayıcıda açman yeterli. Derleme ya da kurulum gerekmez (yalnızca yazı tipleri Google Fonts'tan yüklenir).

Deneylerdeki olasılıklar, eğriler ve başarı çubukları temsilîdir. Model fiyatları Kasım 2026 Anthropic API liste fiyatlarıdır.
